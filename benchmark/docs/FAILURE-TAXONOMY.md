# GeoMark 失败分类（Failure Taxonomy v0.1）

> 评测不只关心「对错」，更关心「怎么错的」。本表用于把失败归因到可比较的类型。
> 自动化归类实现在 `benchmark/tools/summarize.mjs` 的 `classify()`；人工复核时可下调或上调标签。

| 代码 | 名称 | 判据（自动） | 典型表现 |
|---|---|---|---|
| F01 | 图形理解失败 | ✅ 自动：`vision` 模式得分率 < 40% | 配图元素漏读、错读字母、凭空添加关系 |
| F02 | 几何关系失败 | ⬜ **保留标签，无自动检测器** | 用了不成立的相似或垂直关系 |
| F03 | 错误假设 | ⬜ **保留标签，无自动检测器** | 附加了题面未给的条件（如「不妨设为正三角形」） |
| F04 | 计算错误 | ✅ 自动：得分率 70%–99%，思路对但结果错 | 化简、开方、比值算错 |
| F05 | 推理链断裂 | ✅ 自动：得分率 40%–69% | 关键步骤缺失或跳步无法验证 |
| F06 | 约束违规（坐标作弊） | ✅ 自动：`pure` 模式被判定使用坐标法 | 明令禁止建系仍偷偷建系 |
| F07 | 最终答案错误 | ✅ 自动：得分率 < 40%（含 0 分） | 方向性错误、答非所问 |
| F08 | 工具/执行失败 | ⬜ **保留标签**：传输层失败在 Harness 层记为 `provider_error`/`timeout`，不进入本分类 | API 错误、截断、空回复 |

## 使用约定

- 同一作答可同时命中多类；`summarize.mjs` 取优先级：F01（识图）> F06（作弊）> F07 > F05 > F04 > PASS。
- **F02 / F03 / F08 的计数恒为 0，含义是「未实现检测」，不是「从未发生」。** 引用失败分布时只能
  引用 F01 / F04 / F05 / F06 / F07 这五个码；需要 F02/F03 的结论时必须人工标注样本。
- **F06 与其他失败不同**：它不是能力不足，而是**违反实验约束**。命中 F06 的作答在总表中总分记为 0，但保留 `rawTotal`，便于区分「不会做」与「会做但作弊」。
- 分析模型能力时应先剔除 F06 样本，再讨论 F02–F05 的分布，否则会把「作弊被罚」误读为「能力下降」。
