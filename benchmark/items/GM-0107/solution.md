# GM-0107 解析

## 答案

（1）作点 $A$ 关于 $l$ 的对称点 $A'$，连 $A'B$ 交 $l$ 于 $P$；（2）两点之间线段最短；（3）$EF=1$

## 标准解（关键步骤）

1. (1) 作 $A$ 关于直线 $l$ 的对称点 $A'$，连接 $A'B$ 与 $l$ 的交点即为 $P$
2. (2) 依据：两点之间线段最短
3. (3) 取 $B$ 为原点、$BC$ 沿 $x$ 轴，$C(2\sqrt{3},0)$，$E(\sqrt{3},0)$，$BD$ 方向与 $BC$ 成 $30^\circ$，设 $F=s(\cos30^\circ,\sin30^\circ)$
4. $EF^2=s^2-3s+3$，$CF^2=s^2-6s+12$；令 $f(s)=\sqrt{s^2-3s+3}+\sqrt{s^2-6s+12}$，$f'(s)=0$ 得 $s=2$
5. $s=2$ 时 $EF+CF=3$ 最小，此时 $EF=\sqrt{4-6+3}=1$

## 评分要点

1. （3 分）(1) 正确作出点 $P$（作轴对称点后连线取交点）
2. （2 分）(2) 填「两点之间线段最短」
3. （4 分）(3) 用坐标或几何方法把 $EF+CF$ 化为单变量函数
4. （5 分）(3) 求出最小值位置并得到 $EF=1$
