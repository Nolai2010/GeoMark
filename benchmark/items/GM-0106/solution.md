# GM-0106 解析

## 答案

（1）见解析（$AG=2GC$）；（2）① $2$；② $\dfrac{EF}{BC}=\dfrac{2}{3}$

## 标准解（关键步骤）

1. $M$ 为 $BC$ 中点，$O$ 为对角线交点（即 $AC$ 中点），在 $\triangle ABC$ 中 $OM\parallel AB$，$DM$ 交 $AC$ 于 $G$
2. 由中位线定理与相似，得 $AG:GC=2:1$
3. ① $AB=6,BC=8$：内角平分线交点为内心，由坐标 $A(0,0),B(6,0),C(6,8),D(0,8)$ 求得 $I(4,6)$，故 $I$ 到 $BC$（直线 $x=6$）的距离为 $2$
4. ② $AB+AC=2BC\Rightarrow AB:BC:AC=3:4:5$；取 $AB=3,BC=4,AC=5$ 得 $I(2,3)$ 与 $G(2,8/3)$，直线 $GI$ 为 $x=2$
5. 由 $x=2$ 与 $BD$、$CD$ 求交点得 $EF=\dfrac{8}{3}$，故 $\dfrac{EF}{BC}=\dfrac{2}{3}$

## 评分要点

1. （4 分）(1) 利用中位线/相似证明 $AG=2GC$
2. （4 分）① 由角平分线交点为内心求出 $I(4,6)$，得到 $I$ 到 $BC$ 的距离为 $2$
3. （3 分）② 由 $AB+AC=2BC$ 推出三边比 $3:4:5$
4. （4 分）② 求出 $E,F$ 位置并算出 $\dfrac{EF}{BC}=\dfrac{2}{3}$
