# 格物台 · 自用走查指南（10 分钟）

服务已在 **http://127.0.0.1:7788** 运行。按顺序走一遍即可体验全部能力。

## 1. 配置 API 密钥（约 1 分钟）

右上角 **API 密钥** → 按你要用的服务填入对应协议的密钥 → 保存。
- 只存在本机 `config/secrets.json`（已被 git 忽略），绝不进日志与实验记录。
- 顶栏两个圆点变绿表示对应协议已配置。

## 2. 添加一个模型（约 2 分钟）

侧栏 **管理模型** → 顶部「从预设开始」选 **DeepSeek / Qwen / Kimi / MiniMax / ChatGLM / OpenAI / Anthropic** 之一（预设只填协议、地址、模型 ID，均可改）→ 填模型 ID 与显示名称 → **测试连接**：
- 连接成功 → 保存模型；
- 报 `HTTP 401` 说明密钥不对，报 `网络错误` 说明地址不通。

也可以完全自定义：任意 OpenAI-compatible 服务，改接口路径、默认温度/最大词元数、Extra Body JSON。

## 3. 第一轮对话（约 2 分钟）

侧栏选好模型 → 输入系统提示词（可留空）→ 底部输入问题 → **发送**。
观察：
- 右下状态徽标：就绪 → 连接中 → 流式输出中 → 已完成；
- 回答结束后的指标行：结束原因 / 首词元延迟（TTFT）/ 总耗时 / 输入与输出词元；
- 若模型有原生推理，左侧会出现可折叠的「思考过程（原文照录）」。

## 4. 文件输入（约 1 分钟）

侧栏 **选择文件** 上传一个 `.txt` / `.md`（例如放一道题）→ 文件出现在列表 → 在提问中引用它再发送。
实验详情的「模型实际看到的输入」里能看到文件的完整原文包在固定模板中——这就是"模型到底看到了什么"。

## 5. 实验记录与完整性校验（约 2 分钟）

侧栏勾选 **保存实验**（默认勾选）→ 右侧「实验记录」点击任意一条 → 实验详情：
- 系统提示词原文、模型实际看到的输入、实际生效配置（requested vs resolved）、最终回答、词元用量、事件流；
- 顶部 **校验通过/失败**：对实验包逐文件做 SHA-256 校验 + 事件哈希链复核。

命令行同样可以复核与离线重放（不联网）：

```bash
node surfaces/cli/cli.mjs --verify experiments/exp-xxx
node surfaces/cli/cli.mjs --replay experiments/exp-xxx
```

## 6. 换模型重跑（对照实验）

侧栏下拉切到另一个模型（或用管理模型再添加一个），**同样的系统提示词、同样的问题、同样的文件**再发一次。两份实验记录的输入应当逐字节一致——这正是本环境存在的意义。

## 7. CLI 体验（可选，约 1 分钟）

```bash
node surfaces/cli/cli.mjs --list-models
node surfaces/cli/cli.mjs --model <模型id> --experiment "你的问题"
```

## 8. 主题与演示

右上角 **主题** 循环：亮色 → 暗色 → 跟随系统（无刷新切换）。
录屏演示钩子：`http://127.0.0.1:7788/#qa-demo`（对话形态）、`#qa-term`（术语说明）、`#qa-keys`（密钥弹窗）；`?theme=light|dark` 可强制主题。

## 常见问题

| 现象 | 处理 |
|---|---|
| 发送后提示未配置 API 密钥 | 右上角「API 密钥」或模型配置里补填 |
| 测试连接 401 | 密钥错误或无权限；429 为限流，稍后再试 |
| PDF 上传后提示读取失败 | 本环境 PDF 仅记录元数据，转 `.txt/.md` 再附加 |
| 想换端口 | `HARNESS_PORT=8080 node surfaces/web/server.mjs` |

安全提示：服务只绑定本机 127.0.0.1；跨站与重绑定请求一律 403；密钥永不回显。
