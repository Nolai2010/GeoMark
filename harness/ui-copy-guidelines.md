# GeoMark Harness UI 文案规范（ui-copy-guidelines）

> 本规范自 v0.4 起对所有界面文案生效。新增或修改文案前先对照本文件。
> 核心定位：**现代中文产品语言 + 中国视觉审美**。中国风由色彩、字体、留白、排版、图形与动效承载，不由古文承载。

## 1. 总原则

1. 现代、清晰、专业、简洁；可读性 > 可用性 > 信息层级 > 实验效率 > 视觉风格 > 装饰。
2. 禁止拟古 / 武侠 / 仙侠 / 书院式功能命名（择器、出题、呈卷、落卷、拂去、沉吟、钥匙、合上、封印、船夫、天机等一律不得用于功能名称）。
3. 装饰性短句（如空状态的「同题共答，千帆竞渡」）与品牌名（格物台）允许保留少量文化气质，但不得承担功能语义。
4. 已有正式中文译名的技术术语，一律用正式译名，不自创替代词。

## 4. 状态命名

| 语境 | 文案 |
|---|---|
| 运行状态 | 就绪 / 连接中… / 流式输出中… / 推理中… / 已完成 / 失败 / 未完成（truncated） |
| 实验状态（列表与详情） | 已完成 / 失败 / 未完成（完成状态原文，如 truncated） |
| 完整性校验 | ✓ 校验通过，记录完整 / ✗ 校验失败，记录可能被改动 |
| 文件状态 | 上传中…（文件名）/ 上传失败（文件名）/（大小 · 类型） |
| 文件操作 | 移除 |
| 模型信息 | `模型ID · API 地址 · 支持原生推理` |

## 5. 错误提示

- 结构：`[类别] 具体原因（可执行的下一步）`。
- 例：`未配置 API 密钥。请在右上角「API 密钥」设置，或在模型配置中为该模型单独填写。`
- HTTP 错误：`连接失败：API 密钥无效或未授权（HTTP 401）`；`连接失败：接口地址不存在…（HTTP 404）`；`连接失败：请求过于频繁（HTTP 429）`；`网络错误：无法连接到 API 地址（超时或不可达）`。
- **禁止在错误信息中出现 API 密钥 / Authorization 的任何片段。**
- 长错误在消息气泡内换行展示，完整原文进入实验详情。

## 6. 空状态

- 会话空状态：装饰短句 + 一句现代说明（做什么、怎么做）。
- 模型列表为空：引导到「管理模型」从预设添加。

## 7. Tooltip

- 缩写首次出现时在 Tooltip / 术语说明中给出全称：TTFT → 首词元延迟（TTFT）；SSE、SHA-256、HTTP、API、JSON 保留英文缩写。
- 术语说明（点正文中的术语弹出）内容为固定文案，标注「固定文案，非模型生成」。

## 8. 实验状态 / 文件状态 / Provider 配置 / Streaming / 词元统计 / 推理

- 词元统计：`输入词元=N / 输出词元=N`；延迟：`首词元延迟（TTFT）=Nms · 总耗时=Nms`。
- 推理状态：`推理中…`（流式思考）、`思考过程（模型原生推理，原文照录）`（折叠区标题）。
- Provider 配置字段名：协议类型 / 显示名称 / API 地址（Base URL）/ 接口路径 / API 密钥 / 模型 ID / 默认温度 / 默认最大词元数 / 推理 / Extra Body。
- Streaming 状态仅在状态徽标（就绪/连接中/流式输出中…）中体现，不在正文中插入技术词汇。

## 9. 正式中文技术术语表

| 英文 | 界面用词 |
|---|---|
| Token | 词元（输入词元 / 输出词元 / 词元用量） |
| TTFT | 首词元延迟（TTFT） |
| Streaming | 流式输出 |
| Reasoning | 推理 / 思考过程 |
| Provider | 服务提供商 |
| Endpoint | 接口地址 / API 地址 |
| Adapter | 适配器 |
| Manifest | 清单 |
| System Prompt | 系统提示词 |
| User Prompt | 用户提示词 |
| API Key | API 密钥 |
| Base URL | API 地址（Base URL） |
| Max Tokens | 最大词元数 |
| Finish Reason | 结束原因 |
| Completion State | 完成状态 |

保留英文缩写：SSE、SHA-256、HTTP、API、JSON、TTFT（配中文全称）、Extra Body。

## 10. Model-Agnostic 红线

- 预设（Preset）只允许包含：协议类型、API 地址、接口路径、默认模型 ID。
- 禁止任何按模型/服务商身份改变提示词、上下文、工具或流程的代码与文案。
- 协议差异只能出现在 `adapters/specs/*.json` 声明式映射中。
