# GeoMark-Harness v0.6.0 正式发布说明

发布时间：2026-09-13 · 验证方式：**真实浏览器自动化自测 7/7 通过 + npm test 102/102**

## 本版亮点

1. **滚动体系重做（修复"中间对话划不动"）**
   - 根因：flex/grid 子项默认 `min-height:auto`，长内容把聊天区撑破，`overflow` 失效后被页面裁切。
   - 修复：`#app > * / #main / #chat` 全链路 `min-height:0`，`html/body` 锁滚动。
   - 效果：顶栏与左右侧栏**常驻不滚走**，聊天区独立滚动。
2. **跟随模式 + SVG 跳底按钮**：流式输出中用户上翻即暂停自动跟随，右下浮现 SVG 向下箭头按钮，点击平滑跳到最新回复，回底自动隐藏（浏览器实测出现/跳底/隐藏全链路通过）。
3. **Markdown + LaTeX 实时渲染**：本地 KaTeX（零 CDN）+ 自研安全渲染器（先转义再渲染，`javascript:` 等协议不生成链接，代码块内容不被误渲染）；回答与思考过程都渲染，实验详情保留原文。
4. **对话记录体系**：对话自动保存（本机，最近 30 条），刷新后回到上次对话；右栏可恢复/重命名/删除任意一次对话。
5. **实验记录管理**：默认显示名 = 提示词前 24 字（不再满屏编号）；可重命名/删除（含全部文件）；详情弹窗可「恢复为当前对话」。
6. **安全修复全部保留**：同源守卫（跨站/重绑定 403）、密钥策略、SSRF 加固、原型污染清洗、路径校验、安全响应头。
